# Base Presentation

> Sistema inteligente de generación de presentaciones profesionales

Una herramienta que combina **excelencia técnica** con **principios de comunicación efectiva** para crear presentaciones que realmente conectan con tu audiencia.

## 🌟 Características

- **🎯 Navegación no lineal**: Salta a cualquier diapositiva según el flujo de la conversación
- **🎨 Temas profesionales**: 34+ diseños distintivos inspirados en beautiful-html-templates
- **📝 Copy inteligente**: Aplica principios de copywriting y storytelling
- **🎬 Animaciones estratégicas**: Motion graphics con propósito comunicativo
- **🧠 Design Thinking**: Soluciones centradas en las necesidades reales de tu audiencia
- **📱 Responsive**: Funciona perfectamente en cualquier dispositivo
- **⚡ Performance optimizada**: Next.js 15 + Tailwind + reveal.js

## 🚀 Casos de Uso

- **Pitch Decks** para startups e inversionistas
- **Presentaciones educativas** para universidades y colegios
- **Reportes ejecutivos** para empresas
- **Sermones visuales** para iglesias
- **Workshops y talleres** para equipos
- **Product launches** con impacto visual

## 🏗️ Stack Tecnológico

- **Framework**: Next.js 15 (App Router)
- **Presentaciones**: reveal.js
- **Styling**: Tailwind CSS
- **Animaciones**: Framer Motion + reveal.js transitions
- **TypeScript**: Type safety completo

## 📚 Base de Conocimiento

El sistema aplica principios fundamentados de:

- **Copywriting**: Mensajes claros, persuasivos y memorables
- **Storytelling**: Narrativas que conectan emocionalmente
- **Design Thinking**: Metodología centrada en el usuario
- **Graphic Design**: Jerarquía visual, color, tipografía
- **Motion Graphics**: Animaciones con propósito

Ver documentación completa en `.claude/knowledge/`

## 🛠️ Instalación

```bash
# Clonar el repositorio
git clone https://github.com/4peacenfreedom/basePresentation.git
cd basePresentation

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) para ver el resultado.

## 📖 Uso

### Crear una nueva presentación

```bash
# Próximamente: Comando CLI para generar presentaciones
npm run create-presentation
```

### Estructura de directorios

```
basepresentation/
├── .claude/knowledge/     # Base de conocimiento del agente
├── app/                   # Next.js App Router
├── components/            # Componentes React
│   └── presentation/      # Componentes de slides
├── lib/presentation/      # Lógica de generación
│   ├── themes/           # Temas visuales
│   ├── templates/        # Templates de slides
│   └── utils/            # Utilidades
└── public/assets/        # Multimedia (imágenes, videos)
```
